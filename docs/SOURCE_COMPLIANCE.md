# 수집 출처 사전 확인 기록

확인일: 2026-09-14

이 문서는 기술적 robots.txt 확인 결과를 기록합니다. robots.txt는 이용약관상 데이터 재이용 허가를 대신하지 않습니다. 공개 운영 전 운영자가 각 사이트의 최신 약관과 저작권 정책을 직접 확인해야 합니다.

| 출처 | robots.txt 기술 확인 | 현재 어댑터 경로 | 주의사항 |
|---|---|---|---|
| 게임잡 | 응답 확인. 상세검색 및 회사 상세 경로는 robots 제한 목록에 포함되지 않음 | `/Recruit/joblist`, `/recruit/_GI_Job_List`, `/Company/Detail` | 현행 약관과 하단 고지에서 사전동의 없는 복사·복제·가공 및 타인 제공을 제한하므로 서면 허가 전 비활성화 |
| 게임메카 | 응답 확인. 일부 경로 제한, `Crawl-delay: 30` | `/news.php` | 요청 간격을 robots 값 이상으로 적용 |
| 인벤 | 응답 확인. 특정 게시판 등 제한 | `/webzine/news/` | 이용약관 별도 검토 필요 |
| 디스이즈게임 | 응답 확인. 다수 경로 제한, 매우 긴 crawl delay 표기 | `/webzine/news/` | 현재 어댑터는 한 번의 목록 요청만 수행. 반복 요청 확장 금지 |
| PLUDI | 전체 허용 후 `/admin`, `/api`, `/trend/manage` 제한 | `/trend/dashboard/` | 공개 대시보드 HTML에서 제공되는 범위만 사용 |

## 구현된 보호 장치

- 매 요청 전에 robots.txt 확인
- robots.txt 확인 실패 시 기본적으로 전체 차단 처리
- `Disallow` 경로 요청 거부
- 사이트가 지정한 crawl delay와 프로젝트 기본 2초 중 더 긴 값을 적용
- 로그인, CAPTCHA, API 제한 경로 우회 없음
- 뉴스 전문 미저장
- 어댑터별 실패 격리 및 상태 기록
- 채용공고 0건이면 기존 정상 `latest.json` 유지

## 운영 전 사람이 확인할 사항

1. 각 사이트 최신 이용약관에서 자동 수집 및 공개 재배포 가능 범위를 확인합니다.
2. 회사 로고의 복제·캐시·핫링크가 허용되는지 확인합니다.
3. 허용 여부가 불명확하면 운영사에 문의하고, 답변 전에는 해당 어댑터를 사용하지 않습니다.
4. 제한되는 출처는 공식 API, RSS 또는 적법한 사용자 업로드 파일로 대체합니다.

게임잡은 공개 화면 구조와 페이지네이션 파서를 구현하고 테스트했지만 `config/source_policy.yml`에서 기본 비활성화했습니다. 운영사의 서면 허가 또는 적법한 공식 데이터 제공 계약을 받은 뒤에만 `approved: true`로 변경하세요.
